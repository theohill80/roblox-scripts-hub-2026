## Getting Started

First, clone the repository:

```bash
git clone https://github.com/theohill80/roblox-scripts-hub-2026.git
cd REPO
```

For local review, open the appropriate HTML file in a browser, or browse the `scripts/` and `examples/` directories. When making changes, use a separate customized copy rather than modifying the original collection directly.

One possible local arrangement is:

```text

  collection/
  custom/
examples/
  html/
docs/
```
